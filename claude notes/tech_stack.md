# Tech Stack

Quick reference for stack, hosting, and constraints.

- Static HTML5, Hebrew/RTL (`lang="he" dir="rtl"`)
- TailwindCSS via CDN (no local build)
- Press Start 2P font (Google Fonts CDN)
- GitHub Pages from `docs/` folder, custom domain `8bitretro.tech` via CNAME
- No JS framework, no backend, no npm
