Until now the game had levels, but no game around them. You started playing... and went straight into a fight. You died, and a new game started that same moment. Step 4 puts a frame around it.

There was no frame at all. No "level complete", no "Game Over", no start of the game with some nice music. In other words, none of that had been built yet...

{icon:star}Title screen

The game now opens on FIST III, my working title for the sequel, in big shadowed block letters. Press PRESS FIRE, and the first level comes up out of the black. The trick: the title screen is a level. It is a CharPad map in the same level bank, loaded the same way, just never played. So when I draw a real logo, I redraw this map in CharPad and the game picks it up. No code.

{icon:joystick}Game over: when the game ends, back to the main menu? Or a closing chord?

Die, and you get GAME OVER, then CONTINUE with a digit counting down from 9, one per second. Press fire, and the same level starts again with the score back at 0. Let the count run out, and you are back on the title screen. Beat the last level, and the game writes GAME COMPLETE, then the title screen again.

{icon:clock}Fade between levels

The change between levels was a hard cut, and for one frame it showed the new level's graphics in the old level's colours. Ugly. Now the street darkens to black in 8 steps, following the C64's own brightness order, the next level loads in the dark, and it comes back up slowly. About a third of a second each way, and the broken frame is gone. The HUD stays lit the whole time, so you can still read COMPLETE.

{icon:chip}Behind the scenes

A title screen broke every automated test of the level game: they all switch the game on and wait for a fight, and now the game waits for fire. So the test harness learned to press fire on the title screen by itself. A new test runs through the whole loop: game over, the countdown, continue, the fade, game complete, the title screen. 12 tests, all green. Everything outside the level game came out identical, byte for byte.

One honest note: my second level is painted in very dark colours, and on the C64's brightness scale they stay black until the last step. So that level comes in almost like a cut. A brighter level shows the whole fade.
