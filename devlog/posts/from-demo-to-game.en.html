A fight room is not a game. Three days of bugs out, sound in, and levels and fighters turned into data.

{icon:bug}8 October · clean-up

A regression run against v2.0 found 45 stale addresses. Fixing them fixed real things: a flying kick no longer hits twice, and blocking now works against either enemy (3 failing tests down to 0). The enemies' attacks still match v2.0, 28 of 28.

Then the temple, which hung. Now all 22 temple rooms draw with the cave look, including six that used to overflow, all five scrolls can be picked up, and 3,000 frames of walking pass with no hang. The fix cost 0 bytes of code.

The same day, a guide for the artist: which files to deliver (SpritePad for the fighters, CharPad for the world, and a SID tune that plays at $f400).

{icon:note}9 October · sound

Sound effects on the SID: a short noise burst on voice 3, with no extra interrupt. A probe fired 67 of them with 0 problems.

{icon:map}10 October · levels as data

Levels now unpack at run time into one fixed 4 KB area. The decoder is 94 bytes, checked on 325 samples with 0 wrong. Finish a level and "LEVEL n COMPLETE" shows for two seconds, then the next one loads. It also freed 115 bytes of world code.

{icon:fist}10 October · fighters as data

The fighters are now described in one fighters.json: 73 poses, with a checker whose byte count matches the assembler's exactly, 454 = 454. Fifteen tests feed it broken files on purpose.
