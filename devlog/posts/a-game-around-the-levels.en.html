Until now the game had levels, but no game around them. You booted straight into a fight, and when you died a new game started on the spot. Stage 4 put the frame around it.

{icon:star}A title screen

The game now opens on FIST III, my working title for the sequel, in big block letters with a drop shadow. PRESS FIRE, and the first level fades in. The trick: the title is a level. It's a CharPad map in the same level bank, loaded the same way, just never played. So when I draw a real logo, I redraw that one map in CharPad and the game takes it. No code.

{icon:joystick}Game over, continue?

Die, and you get GAME OVER, then CONTINUE with a digit counting down from 9, one a second. Fire, and the same level starts again with the score back to 0. Let it run out and you're back at the title. Beat the last level and the game says GAME COMPLETE, then the title again.

{icon:clock}A fade between levels

The level change used to be a cut, and for one frame it showed the new level's graphics in the old level's colours. Ugly. Now the street darkens to black in 8 steps, following the C64's own brightness order, the next level loads in the dark, and it fades back in. About a third of a second each way, and the broken frame is gone. The HUD stays lit through it, so you can still read COMPLETE.

{icon:chip}Behind the scenes

A title screen broke every automated test of the level game: they all start the game and wait for a fight, and now the game waits for fire. So the test harness learned to press fire on the title by itself. A new test walks the whole loop: game over, the count, continue, the fade, game complete, the title. 12 checks, all green. Everything outside the level game came out byte-identical.

One honest note: my second level is painted in very dark colours, and on the C64's brightness scale those stay black until the last step. So that level comes in almost as a cut. A brighter level shows the whole fade.
